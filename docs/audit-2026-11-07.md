# Kaamos v0.2.0 audit, 2026-11-07

Four auditors (Slint UI, Rust helpers, template/scripts, docs/licensing) and a senior review
that checked every finding against the code (Slint 1.18.1 and ksni 0.3.7 sources). Raw findings
with IDs: `audit-2026-11-07-raw.md`.

**Status 2026-11-08:** the v0.3.0 plan below is done (tag v0.3.0). Deviations: Slint is held with
`~1.18.1` (not `~1.18`); R1 is `tray::spawn_with_status` → `TrayStatus::online()` (plus a 5 s
"show the window if no tray" timer in the template and PulsarFe); NButton got `toggle` for S3.
**Status 2026-11-08 (v0.4.0):** "Before going public" is done except D1 itself (switching the repo
to public; then NARME's CI deploy key can go, and NARME's `release.yml` needs cargo-about notices)
and S6/S7 (focus ring: changes the look, not approved). Deviations: `rust-version = "1.92"`
(Slint 1.18 needs it, not 1.88); `new-project.sh` also refuses Rust keywords and the built-in crate
names. "Later" is still open.

## Assessment

Healthy for a private two-consumer kit; the code follows Slint's own widget idioms, and nothing
shipped today breaks a licence. Biggest risks: R1 (tray "present" check lost in extraction) and
R10 (Slint not actually pinned). Release gate: NARME binaries cannot ship while Kaamos is private
(D1).

## Plan: Kaamos v0.3.0 (done 2026-11-08)

None of these change either app's look.

1. **R1 tray availability.** `assume_sni_available(true)` means `spawn()` never returns `None` for a
   missing SNI host, so the `spawn` doc is wrong.
   - Port NARME's `present: Arc<AtomicBool>` (NARME `crates/narme/src/tray.rs` ~95-108): set it in
     `watcher_online`/`watcher_offline` and add `pub fn online(&TrayHandle) -> bool` (additive).
   - PulsarFe `src/bin/pulsarfe-gui.rs` ~1165/1195 and template `main.rs` ~110/207: hide on close
     only when the tray is online, otherwise quit. Optionally show the window if the tray goes away.
2. **R10 Slint pin.** Change `slint`/`slint-build` `"1.18.1"` to `"~1.18"` in:
   - the workspace `Cargo.toml`, `template/Cargo.toml` and the README;
   - PulsarFe `Cargo.toml` and NARME's workspace `Cargo.toml`.

   Fix the "pinned" wording in the comments and CLAUDE.md.
3. **S2 + S4.**
   - NButton `key-pressed`: `if (!root.enabled || event.repeat) { return reject; }`.
   - NSwitch: ignore `event.repeat`.
   - ValueField wheel TouchArea: `enabled: root.enabled`.
4. **S3 screen readers.** `accessible-checkable: true` on NSwitch (role switch), Segmented items
   (radio-button), NavItem (`accessible-item-selectable` / `selected`) and NButton when it is a toggle.
5. **S1 bindings.** Document "bind `checked` / `current-index` with `<=>`" in `widgets.slint`.
   - PulsarFe `ui/main.slint` ~272 (Segmented `current-index: root.selected-profile - 1`): switch to
     `<=>` on an index property set from Rust.
   - NARME `main.slint` ~676 (NSwitch inside a PopupWindow, re-instantiated on every open): latent
     only; leave it or convert.
6. **R2 autostart path.** In `autostart::enable`, strip a trailing " (deleted)" from `current_exe`,
   and return `Err` if the path does not exist.
7. **Template.**
   - Ship `THIRD_PARTY_NOTICES` plus the OFL-Inter and MIT-Feather texts, and install them in the
     PKGBUILD.
   - Add a placeholder app icon (svg) and install it.
   - README: commit `Cargo.lock` (PKGBUILD runs `cargo fetch --locked`).
8. **R3 Exec escaping.** Escape at the string layer (`\\$`, `\\\\`, `\\"`), write `%` as `%%`, and
   reject control characters in Name/Comment/Icon. Fix the test.

Then: tag v0.3.0; update PulsarFe (`./check.sh`, screenshot) and NARME (Slint pin; 24-preview pixel
compare, fmt/clippy/test/MSRV 1.92); update the design system artifact if anything visible changes.

## Before going public

- **D1:** make Kaamos public (or vendor it into NARME's source release) before the first NARME
  binary release. Add cargo-about (or similar) notices for the statically linked crates to NARME's
  `release.yml`.
- **D5:** rename `KitTray` → `KaamosTray` (keep a re-export alias).
- **D6/D7:** SPDX headers in `template/`, `new-project.sh`, `check.sh` and the gallery; add a
  copyright line.
- **R11:** `rust-version = "1.88"` (`as_chunks`).
- **D8–D10:** doc nits.
- **T1/T2 `new-project.sh`:** reject `$`, backtick, control characters and an empty title. The
  title is sourced by makepkg through `pkgdesc`. Build in `mktemp -d`, then `mv`.
- **T6:** reserved names (build, deps, examples, incremental).
- **S10:** ValueField `enabled` defaults to false; Dialog tone 1 comment.
- **S6/S7:** keyboard focus for Segmented/NavItem and a focus ring. This changes the look under
  keyboard focus, so it needs the owner's approval or has to be opt-in.
