# Kaamos audit — raw findings from four auditors (to be verified)

Repo: /home/olli/kaamos (HEAD 303632e = tag v0.2.0). Consumers: /home/olli/PulsarFe, /home/olli/NARME, template/.
Line numbers are the auditors' claims; verify them.

## S — Slint UI (crates/ui/ui/*.slint, crates/ui/src/lib.rs)
- S1 HIGH: Segmented and NSwitch assign to their own `in-out` property (widgets.slint ~115 `root.checked = !root.checked`, ~201/209 `root.current-index = i`), which breaks a consumer's one-way binding (`current-index: expr`). PulsarFe ui/main.slint ~272 `Segmented { current-index: root.selected-profile - 1; selected(i) => ... }`; NARME crates/narme/ui/main.slint ~676 `NSwitch { checked: i == 0 ? root.link-line : … }`. After a failed/refused change the widget stops following the model.
- S2 MED: NButton (widgets.slint ~48-54) FocusScope key handler fires clicked() while disabled (FocusScope keeps focus; Slint 1.18 does not check enabled on key events) and on key auto-repeat (event.repeat not checked). NSwitch toggles repeatedly on held Space.
- S3 MED: accessible-checked never exposed because accessible-checkable is not set (AccessKit adapter needs it). NSwitch should be role switch + checkable; Segmented radio-button; NavItem tab with item-selectable/selected.
- S4 MED: ValueField scroll-event (widgets.slint ~333-341) steps while disabled (TouchArea not gated by enabled).
- S5 MED: ValueField keeps uncommitted typed text after focus leaves (only reset on accepted or text change).
- S6 MED: Segmented and NavItem not keyboard reachable (no FocusScope).
- S7 MED: No visible focus on kind 1/2 NButton (border-width 0) or on checked NButton/NSwitch (already accent border).
- S8 LOW: InfoTip/InfoLayer: (a) bubble stays if hovered tip is destroyed; (b) position captured once (scroll/resize); (c) narrow window <348px → negative x, no min clamp, fixed 340px width; (d) PopupWindow unsupported.
- S9 LOW: min-width too small: NButton with icon (missing 26px), NSwitch (64 vs 68px needed); no text elision.
- S10 LOW: ValueField.enabled default false (others true); Dialog tone 1 documented as "warning" but uses Theme.error.
- S11 LOW: duplicate screen-reader nodes from inner Text; ValueField LineEdit without accessible-label.
- S12 LOW: ValueField one step per wheel event regardless of delta (touchpad floods), always accepts.
- S13 LOW: kaamos_ui::ui_path() bakes CARGO_MANIFEST_DIR; stale rlibs after local directory rename broke `cargo build` until `cargo clean -p kaamos-ui` (env issue; document).
- S-nits: muted on surface-3 4.41; selected Segmented fill vs track 2.63:1; hardcoded tints duplicate theme colours; Inter only registered in kaamos.slint.

## R — Rust helpers (crates/kaamos)
- R1 MED: tray.rs ~135-137/155 `assume_sni_available(true)` + watcher_offline returning true ⇒ spawn returns Some even with no SNI host (GNOME without extension); apps hide on close based on tray.is_none() ⇒ unreachable hidden process.
- R2 MED: autostart::enable writes exe path without checking; current_exe() after pacman upgrade gives "/usr/bin/x (deleted)"; AppImage /tmp mount; cargo run target/debug.
- R3 MED/LOW: Exec escaping not per Desktop Entry spec (backslash layer, `%` → `%%`, non-UTF-8 lossy, newline injection in Name/Comment/Icon); test asserts wrong output (autostart.rs ~29-42, ~96).
- R4 LOW: paths.rs ~35-38 relative XDG_* not ignored; empty HOME gives relative path → writes in cwd.
- R5 LOW: platform::init: XDG_ACTIVATION_TOKEN not removed from env; X11 DESKTOP_STARTUP_ID not handled; Qt backend drops hook; window re-shown from tray has no activation token (ksni::current_xdg_activation_token unused).
- R6 LOW: tray::update blocks the UI thread waiting on the tray thread; possible deadlock if a ksni callback waits on UI thread; redundant compare+clone.
- R7 LOW: TrayImage::Rgba no size validation; `as i32` wrap.
- R8 LOW: poll::drain_every never reports disconnect, timer runs forever; unbounded drain; interval 0 busy loop.
- R9 LOW: autostart write not atomic; is_enabled ignores Hidden=true / X-GNOME-Autostart-enabled=false; exists-then-remove race; app_id unvalidated.
- R10 LOW/MED: Slint not pinned: `slint = "1.18.1"` is ^1.18.1; unstable-winit-030 may break on 1.19; template projects have no lock initially.
- R11 NIT: no rust-version (as_chunks needs 1.88); broken doc link [`tray`] with --no-default-features; ksni types public (KitTray, TrayHandle = ksni Handle); TrayState::id changeable via update but read once; errors discarded (.ok()); kaamos depends on slint with all default features.

## T — Template and scripts (new-project.sh, template/)
- T1 MED: shell injection: title only rejects `"` and `\`; goes into PKGBUILD `pkgdesc="__TITLE__"` which makepkg sources ⇒ `$HOME`, backticks execute (confirmed by sourcing).
- T2 MED: control chars/newline/empty title not rejected; sed failure leaves half-made dir with placeholders; rerun refused ("already exists"). Fix: reject [[:cntrl:]] and empty; trap cleanup or build in mktemp then mv.
- T3 MED: Icon=<app> in .desktop and autostart, but template ships/installs no icon.
- T4 MED: licence compliance: template PKGBUILD declares MIT+OFL but installs only LICENSE; no THIRD_PARTY_NOTICES, no OFL/Feather texts in generated apps.
- T5 LOW/MED: PKGBUILD `cargo fetch --locked` fails if Cargo.lock not committed; template never creates/mentions it.
- T6 LOW: app-id regex accepts build/deps/examples/incremental which cargo rejects as bin names.
- T7 LOW: template worker thread never joined; Quit may cut a save in flight; unsaved edits silently discarded.
- T8 LOW: worker panic ⇒ UI stuck "Working…" (no disconnect / error reply).
- T9 LOW: autostart Exec from current_exe (same as R2).
- T10 LOW: tray tooltip stale after Save (Reply::Saved doesn't update tray).
- T11 LOW: no single instance; --tray with no SNI host hides app (same root as R1).
- T-nits: usage prints `set -euo pipefail` (sed 2,9p); `cp -r` without `--`; grep|while read path mangling; KAAMOS_PATH with `|&"` breaks sed/TOML; .desktop Comment==Name warning; PKGBUILD no url=; repo check.sh never builds template; 50 ms drain timer wakes 20×/s forever.
